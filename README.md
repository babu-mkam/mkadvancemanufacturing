# MK Advance Manufacturing — B2B Manufacturing Website

Static, responsive website built from the supplied `MK Advance Manufacturing` company presentation.

## Source fidelity
- Brand red sampled from the presentation: `#E8241A`.
- Dark brand panel/text: `#1A1A1A`.
- Content is restricted to facts and terminology present in the presentation.
- Facility images are extracted from the supplied presentation and reused as website assets.
- No pricing, stock, customer names, contact details, certifications, addresses beyond Bengaluru, or other company information was invented.
- The site uses an RFQ-first commerce pattern rather than inventing a conventional retail catalog or checkout flow, because the presentation does not provide products/prices/SKUs.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

Example:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
